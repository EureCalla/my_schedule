# your_schedule

甘特圖編輯介面（雛形階段）。沿用 Excel「格子上色排工作」的習慣，在瀏覽器裡操作。

- UI：HTML 前端（HTML / CSS / JavaScript），後端只用 Python 標準庫伺服靜態檔，不需安裝套件
- 資料：v3 起存在共享槽（多人共用），以 VR20 帳密登入；瀏覽器 `localStorage` 只留未存檔的草稿。仍可匯出／匯入 JSON 備份

## 啟動

```bash
python main.py
```

開啟 http://localhost:8520 。改完 `static/` 的檔案，瀏覽器重新整理即可看到。啟動時會自動套用尚未執行的 migration。

## 頁面

| 頁面 | 說明 |
|------|------|
| 登入（`/login.html`） | 版面仿 fellami-client；帳密與 VR20 系統相同（`vr20_data.db` 的 `accounts`），帳號不分大小寫。上方燈號顯示共享槽上的排程資料庫是否連得到。瀏覽器只記住帳號，不存密碼 |
| 排程表清單（`/sheets.html`） | 列出所有人公開的排程表＋自己的私人表；「擁有者」可篩選全部／我自己／某位同事。自己的表可切換「公開」；「＋ 新增排程表」建立後直接開啟（預設公開） |
| 甘特排程（`/index.html?sheet={id}`） | 原本的甘特圖編輯畫面，見下方「操作」 |

開啟甘特頁時：

- **自己的表**：自動取得編輯鎖，只有你能改；按「💾 存檔」或 `Ctrl+S` 把整張表送回，存成新版本（舊版保留）。工具列顯示「● 未存檔」／「已存檔 vN」
- **別人的表**、或自己的表正在別的視窗／電腦編輯中：唯讀，只能切換日／週／月、收合分類、調整欄寬、匯出 JSON
- 編輯中每 5 分鐘自動續約；「← 清單」、登出或關閉分頁時釋放編輯鎖。沒正常釋放（當機、斷線）的鎖 30 分鐘後自動失效
- 有未存檔的修改時，離開前會提醒；草稿會留在這台電腦的瀏覽器，下次開同一張表可選擇載入
- 改排程表名稱（點左上角名稱）後存檔，清單上的名稱會一起更新

## 多人共用資料庫（v3 起）

| 項目 | 位置 |
|------|------|
| 索引 db | `\\mpi-file01\VPCRD2-AI\00_Database_Center\vr20_schedule.db` |
| 排程表本體 | `\\mpi-file01\VPCRD2-AI\10_Schedule\{帳號}\{排程表 id}\v0001.json`（每次存檔一個新檔，舊版保留） |
| 帳號 | `vr20_data.db` 的 `accounts` 表（只讀） |

初始化（建立 db 並套用 `migrations/` 下尚未執行的 migration，可重複執行）：

```bash
python models.py --init
```

API（`api.py`，登入後以 HttpOnly cookie `ys_session` 識別，server 重啟需重新登入）：

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/health` | 排程 db 是否連得到 |
| POST | `/api/auth/login`、`/api/auth/logout` | 登入／登出 |
| GET | `/api/me` | 目前帳號 |
| GET / POST | `/api/sheets` | 看得到的排程表清單／新增排程表 |
| GET | `/api/sheets/{id}` | 排程表資訊與目前版本內容 |
| POST | `/api/sheets/{id}/lock`、`heartbeat`、`unlock` | 編輯鎖 |
| POST | `/api/sheets/{id}/save` | 整表存回成新版本 |
| POST | `/api/sheets/{id}/public` | 切換公開 |

## 操作

| 功能 | 做法 |
|------|------|
| 建立排程塊 | 工具列選「🖌 建立排程塊」，於工作列按住滑鼠橫向拖曳（單擊＝一格）；顏色依工作所屬分類自動決定。緊鄰「沒有文字」的段會併成一段，緊鄰有文字的段則另起一段 |
| 預計／實際 | 按下「建立排程塊」或「清除」時，按鈕下方會彈出「預計排程／實際執行」選單，選完即收起，按鈕上會標出目前的種類（例如「建立排程塊（預計）」）。預計排程為分類淡色；實際執行為同色相的高彩度粗斜線，圖層蓋在預計排程上面，兩者可以重疊、互不切割（同一種之間仍會互相蓋掉／合併）。圖例列右側有兩種樣式的對照 |
| 清除 | 選「🧽 清除」後拖曳範圍，只清除目前所選種類（預計或實際） |
| 移動 | 選「↔ 移動」後按住排程塊左右拖曳；起點貼齊目前尺度的格子（週＝週一、月＝1 號、日＝當天），遇反灰再往後貼到工作日，工作天數與文字不變，落點上原有的排程會被蓋掉 |
| 不排工作（反灰） | 日檢視點表頭日期、週檢視點表頭週數，勾選「不排工作」並可填原因（直式顯示在灰欄上）；週六日預設反灰，可個別取消；月檢視不可設定 |
| 編輯段落 | 選「👆 選取」點段落，或任何模式下右鍵點段落：改段落文字（開發／微調／測試…）、工作天數、刪除 |
| 里程碑 | 選「▲ 里程碑」點格子新增，點既有 ▲ 編輯；滑鼠移上去顯示名稱與備註 |
| 工作 | 滑到工作名稱出現 ✎ ↑ ↓ 🗑；滑到分類格出現「＋工作」與分類上下移；點分類名稱可改名或刪除 |
| 狀態 | 點狀態格依序切換：空白 → △ → v |
| 排程表名稱 | 點左上角的名稱（預設 your_schedule）即可修改；瀏覽器分頁標題與匯出的 JSON 檔名會跟著改 |
| 分類欄寬度 | 拖曳表頭「分類」右緣可調整寬度；分類名稱放不下時以「…」截斷，滑鼠移上去看全名 |
| 分類收合 | 分類格左上的 ▾ / ▸；收合後以淡色顯示該分類所有排程 |
| 分類顏色 | 每個分類自動配一個顏色（色盤依序輪替），顯示在「分類顏色」列；點分類名稱或該列的色塊可改名、改色。改色用一條紅→紫的色相拉條，彩度與亮度固定為淡色；鮮豔色保留給之後的實際完成排程（匯入或舊資料的顏色也會限制在彩度 ≤ 0.2、亮度 0.8～0.92） |
| 復原 | 「↶ 復原」或 `Ctrl+Z`（最多 50 步） |
| 時間尺度 | 工具列「日／週／月」切換，預設為週；切換後會記住並捲到目前進度 |
| 時間範圍 | 工具列「起始」月份與「月數」；排程存的是絕對日期，改範圍或尺度不會位移 |
| 備份 | 「匯出 JSON」下載、「匯入 JSON」覆蓋（可復原）；「重置為示範資料」回到初始內容 |

時間尺度（資料一律以「天」儲存，三種檢視只是粗細不同）：

- **日**：一格＝一天，上層為月份、下層為日期，週末淡色
- **週**（預設）：一格＝一週（週一開始）。下層為當年第幾週，每年以第一個禮拜一那週為第 1 週，一路累加到 52 或 53；上層依該週週一落在哪個月份分組，所以每月有 4 或 5 格
- **月**：一格＝一個月，上層為年份

在某個尺度下拖曳建立排程塊，會涵蓋該格代表的整段日子（日＝一天、週＝週一到週日、月＝整月），其中反灰的日子不算工作天，例如週檢視塗一週＝週一到週五 5 個工作天。較粗的尺度下，排程依實際日子按比例畫在格內，例如只排週一到週五的段在週檢視會佔該格的 5/7。表頭各格滑鼠移上去可看對應日期。

目前進度：在今天所在格子的左緣畫一條深紅色直線（日＝今天、週＝上週與這週之間、月＝本月），表頭該格也標深紅；開啟頁面與切換尺度時會自動捲到這條線附近。

不排工作（反灰）與自動遞補：

- 排程記「起始日＋工作天數」，結束日跳過反灰日往後算，區塊在畫面上連續。例如 3 個工作天拖到週五 → 週五～下週二
- 之後新增或取消反灰，跨到的排程會自動延長或縮短
- 日檢視顯示每個反灰日的灰欄；週檢視只有整週 7 天都反灰才整欄反灰（週末與單日假期只在日檢視看得到，但排程一樣會避開）
- 拖曳範圍全是反灰日時不會建立排程塊；中間只隔著反灰日的兩段無文字排程會合併（例如週五與下週一）

舊資料載入時自動轉換：每月 4 區段格式的第 n 區段 → 該月第 n 個禮拜一那週；週格式的每一週 → 週一到週日 7 天，里程碑放在週一；起訖日格式 → 起點貼到工作日、工作天數＝區間內的工作日數（整段落在週末的排程會移到下一個工作日、算 1 天）。

## 檔案

| 檔案 | 說明 |
|------|------|
| `main.py` | 程式入口，伺服 `static/`，`/api/*` 交給 `api.py` |

| `mpivr20_cms.py` | 路徑與 port 集中管理 |

| `migrations/` | schema migration（依檔名順序套用） |
| `static/index.html` | 頁面骨架：工具列、圖例、甘特主體、對話框 |
| `static/style.css` | 版面與配色 |
| `static/store.js` | 資料模型、日期工具、自動儲存、復原、匯出入、示範資料 |
| `static/timescale.js` | 日／週／月時間尺度：格子切分、表頭分組、日期與 px 位置換算 |
| `static/gantt.js` | 甘特圖繪製與滑鼠操作 |
| `static/app.js` | 甘特頁進入點：讀取排程表、編輯鎖、存檔，綁定工具列 |
| `static/common.js` | 三頁共用：呼叫 API、登出、時間格式 |
| `static/login.html` / `login.css` / `login.js` | 登入頁（仿 fellami-client） |
| `static/sheets.html` / `sheets.css` / `sheets.js` | 排程表清單與篩選 |
| `DESIGN.md` | UI 設計與資料模型紀錄 |
